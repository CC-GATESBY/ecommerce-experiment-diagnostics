## 比较量与区间

每策略/容量报告两臂人数及conversion数、p0、p1、delta=p1−p0、实际c=K/N和G=10000×c×delta，G称每万候选记录的容量标准化组间差额，不是新增客户、预算节省或ROI。

沿用原处理臂分别进行记录级bootstrap，完整25个固定选中标记与conversion形成联合类型；同一次重抽供全部策略/容量和差值共享。每策略五个嵌套容量且100%全选，实际成员类型最多5^5种，交叉两臂和标签最多12,500种；超过上限视为实现问题。只保留压缩类型，不建1,000×数百万矩阵。PCG64 seed20260924，1,000次，固定名单和原实际c，linear经验2.5%/97.5%区间。

零分母返回不可计算，不加极小数；成功或失败单元<10沿用稀疏标记，负差保留，有效/失败重复明确报告。不同seed/联合类型导致旧简单规则区间可不同，但原名单、点估计和计数须一致。区间只条件于固定模型、名单和发布样本，不校正旧test使用或适应性分析，不包含学习、发布抽样、跨期迁移和成本风险；辅助比较不是同时置信保证，正区间不是新的确认性显著结论。

## Qini辅助定义及原E2范围调整

本轮执行前明确以30%直接G差承担主决策，原v4 E2的未归一化Qini面积降为辅助描述，不因结果再调换指标。

五策均在名义0%至100%、步长1%的网格取K=floor(c_nominal×N)，横轴用实际K/N。非空前缀Q=Y_T−Y_C×N_T/N_C；实际空前缀Q(0)=0。实际正容量无control时Q不可计算，曲线保留缺口，整条面积不跨缺口积分，不人为补0或平滑负值。

约定直线L(c)=c×Q(1)；与固定哈希RANDOM的有限样本实测曲线分别标记。按实际c以梯形法积分Q−L，命名“固定1%网格下的未归一化Qini面积近似”。不除以完美曲线，不称[0,1]系数，不与G比较数值大小，不跨不同N的阶段比较原始面积。只有点估计，没有完整曲线/面积区间；面积最大也不改变候选。
