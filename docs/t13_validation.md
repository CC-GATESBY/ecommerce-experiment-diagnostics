## 运行、资源与复跑

专用 Python 3.11.15、JDK 17.0.19、PySpark/Spark 3.5.8；local[4]、Driver4g、UTC、shuffle32，无Hive。一个 FactReader 上下文、1次真实 Parquet 加载，按需缓存事实、first_seen、品牌和用户日，最终释放并正常停止Spark；不收回事实或用户日清单。只收回有明确上限的日汇总（31）、日期×维度汇总（124）、unknown覆盖（≤4）、品牌映射（≤200）及标量。

人工启动至完成31.673秒（Spark工作部分30.151秒）；真实启动至完成122.385秒（工作部分120.821秒）。均首次成功，无失败或额外真实重跑，耗时只作执行记录，不是性能基准。四表目录合计 7,284,665 bytes。累计新增产物采样高水位 220,222,964 bytes（0.205 GiB），低于10 GiB；最低空闲 563,547,844,608 bytes（524.845 GiB），高于150 GiB。预算覆盖 `.local/t11` 的新人工空间和 `.local/t13` 的缓存/临时文件/输出/日志，每至多2秒检查。峰值内存 `not_measured`，没有为测量申请管理员权限或重跑。

配置模板 [metrics.example.json](../config/metrics.example.json) 的空 registry_path 会拒绝运行；实际 `config/metrics.local.json` 与全部运行目录已确认被忽略。以下命令在实际项目根执行，新run不得存在；真实复跑须有当轮授权。预算初始值必须在本轮前实测 `.local/t11` 与 `.local/t13` 总字节，累计不重置：

```sh
".venv/bin/python" -m unittest discover -s tests -p test_metrics.py -v
".venv/bin/python" scripts/run_metrics.py --stage synthetic --runtime-config config/local.yaml --run-dir ".local/t13/<NEW_SYNTHETIC_RUN>" --budget "<LOCAL_BUDGET_JSON>"
".venv/bin/python" scripts/run_metrics.py --stage real --runtime-config config/local.yaml --config config/metrics.local.json --synthetic-gate "<PASSED_SYNTHETIC_VALIDATION_JSON>" --run-dir ".local/t13/<NEW_REAL_RUN>" --budget "<SAME_LOCAL_BUDGET_JSON>"
```

预算JSON字段为 initial_bytes、max_new_bytes（≤10737418240）、minimum_free_bytes（≥161061273600）。真实入口校验人工通过收据与代码/契约指纹，防止用旧测试放行新代码。先staging，全检查通过且Spark正常停止后发布complete；模板、代码、脱敏汇总和本文可以提交，明细与本机路径不提交。
