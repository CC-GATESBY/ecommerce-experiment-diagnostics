# 已知购买率效应模拟 v1

2026-09-21，在人工测试及真实运行前冻结；参数见`config/injection.json`。仅复用cohort-oct-01全部84,165人的cohort_key与post_converted，检查scope及原完成证据，不查询金额、原user_id或其他数据表。所有未返回者保留。

原post_converted作为Y0，p0=sum(Y0)/N。它是模拟采用的基准潜在结果，不代表历史中没有其他营销。S0的delta=0；S1的delta=p0/10，即相对全队列基准提高10%，不是增加10个百分点、Criteo效果或购物车实验盈利门槛。

先按64位小写十六进制cohort_key升序排列，再由NumPy Generator(PCG64(20260921))生成一组U。分组前完整构造两个场景的潜在结果：S0直接复制Y0；S1令q=delta/(1-p0)，Y1=Y0+(1-Y0)×I(U<q)。只允许0→1，原1保留，是人为单调机制，不是真实优惠券的无害性假设。检查0≤delta≤1−p0；p0=1时拒绝正向注入；不裁剪q、不改Y0、不强制翻转数。两个场景共用U。

随后才分组。唯一实验ID为`rees46-injected-v1-0001`；payload的ASCII/UTF-8字节为`rees46-injected-assignment-v1|` + ID + `|` + cohort_key。SHA256前8字节按big-endian无符号整数解释，小于2**63为A，否则为B。键与ID之外的结果不参与分配，不配平。原A/A接口及前缀不变。两场景共用分组，A观测Y0，B观测Y1。

统计沿用`docs/statistical_contract.md`的购买率未合并Wald-z（每组成功/失败格≥10）、B−A、双侧alpha=.05和95%CI，以及全部入组人数50:50的SRM（p<.001）。状态、SRM标记和不显著结果均保留。原方法与稀疏处理不变。

分别保存设定期望delta、生成真值tau=K/N、单次估计hat_tau及误差hat_tau−tau。区间是否包含tau仅是一次覆盖指示，不以包含真值或显著性作为工程通过条件。用整数/Fraction核对S1估计−S0估计=仅B组翻转数/n_B；这不是现实实验可用的通用纠偏，因为现实中无法同时观察两套潜在结果。

人工Monte Carlo只用100人（20个1、80个0）、delta=.08、q=.1，PCG64独立seed20260922、500次。每次K的二项期望8、方差7.2，平均K的MC标准误sqrt(7.2/500)。预先用±6个MC标准误检查明显实现偏离，不要求单次或平均精确等于8，不按结果调整阈值。这是注入机制检查，没有模拟检验检出率，不是功效曲线。

真实队列只执行一对S0/S1。用户级Y0/Y1/U及分配独立保存在被忽略的`.local/t55/`；不回写队列或业务指标，不生成金额、订单、ROI。最多512MiB新增产物，至少150GiB空闲。单次模拟不能证明检出率、区间长期覆盖、真实策略效果或投入价值；CUPED及完整功效分析未执行。
