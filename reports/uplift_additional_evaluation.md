# 旧test追加比较：响应模型仍值得保留吗？

**继续保留响应模型这一开发候选，简单规则仍是业务迁移的基准。** 在同样覆盖30%记录时，响应模型相对简单规则的G差为 **+4.3145，成对95%经验区间[3.3044, 5.2780]**，保持了valid阶段的正向线索。但这份test早已用于TARGET-02，建模发生在已知先前简单规则结果之后；本轮是追加公开基准比较，不是全新独立留出确认，更不是部署批准。

## 相同覆盖人数，额外比较量是多少？

本次原test共2,794,557条，各策略30%均选838,367条；未按处理臂配额、未删除未转化记录。G的单位统一为**每万候选记录的容量标准化组间差额**：10,000×实际覆盖比例×选中范围的两臂conversion率差。它不是实际新增客户预测、预算节省或ROI。

## Qini回答排序形态，30%比较回答固定容量选择

在冻结的0–100%、每1%网格上，Q=选中treatment转化数−选中control转化数×两臂人数比。横轴是实际K/N；参考直线L(c)=c×Q(1)，与固定哈希RANDOM的实测曲线不同。

| 排序 | 固定1%网格下的未归一化Qini面积近似 |
|---|---:|
| RANDOM | −28.1339 |
| FROZEN_SIMPLE | 553.7870 |
| RESPONSE_MODEL | 1,077.2355 |
| S_LEARNER | 1,054.2555 |
| T_LEARNER | 865.2054 |

面积是Q−L的梯形积分，只作同一N下的辅助排序摘要；不是[0,1]系数，也不能与G数值大小直接比较。实际RANDOM面积可偏离0，负值未裁剪。全部[505个网格点](model_evaluation/qini_grid.csv)及[面积表](model_evaluation/qini_area.csv)保留；RANDOM和简单规则的1%前缀对照转化数分别只有4、9，已标稀疏。没有曲线或面积置信区间，不用面积排名决定模型。主决策的不确定性仍由30%成对G区间承担。

## 条件式迁移决定

模型提供了相对简单规则的额外比较量，但增加了十二个处理前特征的可获得性、稳定口径、模型版本、评分和解释要求；没有测量实际维护成本，不能称成本下降或ROI提高。匿名f列不能命名成消费力或价格敏感，也不能直接映射为发券名单；高响应本身不保证高增量。

**唯一优先下一步：取得一份此前未用于方案选择的目标电商随机干预数据，包含可解释的处理前特征及实际触达/干预成本，再事先固定响应模型与简单规则的评价方案。** 若额外差额在该证据下仍有支持、字段可实现且成本与护栏允许，才进入真实业务试验准备；若优势不清楚、成本抵消或字段不可靠，则保留简单基准，不继续在旧test上改特征找优势。这里没有确定性投放比例或已获批预算。

本次按原treatment臂、记录单位做1,000次联合bootstrap，PCG64 seed=20260924，同次抽样供全部固定名单使用，保留重叠。区间条件于本次固定模型、排序和公开样本；不校正此前test使用、适应性分析和多项辅助比较，也不涵盖学习、非均匀发布抽样、跨期迁移或成本风险。不能据正区间恢复原广告主真实incrementality，不能把它称为新的确认性显著结论。原TARGET-02历史报告保持原样。
